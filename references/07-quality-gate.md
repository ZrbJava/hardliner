# 07 交付前质检

写完逐项打钩。任何一项 ✗，只改对应段落，不要整体重写。

---

## A. 抓人（前 10 秒决定 80% 的流量）

| # | 检查项 | 通过标准 |
|---|---|---|
| 1 | 首句形态 | 第一句是一句判断，不是故事开头、不是问候；出现"大家好/我是/今天分享"为 ✗ |
| 2 | 信息缺口 | 第一句让人产生"为什么"或"凭什么"；纯陈述且无冲突为 ✗ |
| 3 | 前 8 个字 | 手机小窗预览时，前 8 字能读出冲突或人群；读不出为 ✗ |
| 4 | 公式外露 | 全篇 `你不是X，你是Y` 不超过 1 次，且不在首句；超过为 ✗ |

## B. 留人（完播）

| # | 检查项 | 通过标准 |
|---|---|---|
| 5 | 失控点 | 有一个具体的"当场接受了不该接受的事"的处境，能一句话说清；只有状态描述为 ✗ |
| 6 | 归因反转 | 有一段把责任从"他坏"翻到"结构/成本/试探"；没有为 ✗ |
| 7 | 机制唯一 | 全篇只讲一个机制，且讲清了"为什么"；两个以上，或只报名字为 ✗ |
| 8 | 符咒名 | 有一个 4–6 字、能默念、能不加解释懂七八成的名字；没有为 ✗ |
| 9 | 支撑递进 | 支撑部分至少三层，一层比一层难堪；并列举例为 ✗ |
| 10 | 方法可执行 | 至少 2 条能让人今天就做；给"要自信"这类为 ✗ |

## C. 传播（截图、转发、关注）

| # | 检查项 | 通过标准 |
|---|---|---|
| 11 | 截图价值 | 结尾有一句能单独截图的话；没有为 ✗ |
| 12 | 转发动机 | 观众能想到一个"该发给他"的具体的人；想不出为 ✗ |
| 13 | 位置移动 | 读完的位置和读完前不同（受害者→共谋者 / 模糊→有名字）；相同为 ✗ |
| 14 | 互动设计 | 评论区置顶是"补充一句"，不是"求点赞"；没有为 ✗ |

---

## D. 语体质检（最容易翻车的一组，必跑）

| 检查 | 通过标准 |
|---|---|
| **土：判决公式** | `你不是X，你是Y` ≤1 次且不在首句 |
| **土：身体反应词** | 喉咙发紧 / 手心出汗 / 耳朵发烫 / 心里咯噔 ≤1 个 |
| **土：喊话词** | 全文 0 个：听好了 / 记住 / 说白了 / 讲真 / 说实话 / 这条别划 / 我告诉你 |
| **土：江湖词** | 全文 0 个：搞钱 / 向上社交 / 破防 / 扎心 / 拿捏 / 松弛感 / 钝感力 / 磁场 / 能量 / 闭环 / 颗粒度 / 底层逻辑 / 认知觉醒 / 降维打击 / 狠一点 |
| **土：反问密度** | 反问 ≤2 个，且不相邻 |
| **土：排比组数** | 排比最多两组，每组 ≤3 句 |
| **土：劝服式收尾** | 无"从今天起，把X从你的字典删掉""愿你……" |
| **自述：我** | 全文"我" ≤2 次，且只用于判断或命名，**不用于经历** |
| **自述：时间锚点** | 无具体某一天开场（大年初二 / 上周三晚上九点） |
| **自述：对话剧本** | 无"他说…你回…他又说…"三轮以上；话术只给观众那一句 |
| **自述：自证权威** | 无"我见过太多人""我带过几百个学员""这个行业我太熟" |
| **自述：情绪自陈** | 无"我当时特别委屈""说不难受是假的" |
| **人称位置** | 前三分之一不出现"你"；出现为 ✗ |
| **人称密度** | 全篇"你" ≤10 次 |
| **句式长短** | 平均 18–26 字；最长句 ≤45 字；**全篇不许全是 15 字以内的短句** |

## E. 无效内容红线

| 检查 | 通过标准 |
|---|---|
| 无商品 | 全文无商品名、无价格、无优惠、无链接、无"左下角" |
| 无购买引导 | 无"下单/入手/囤起来/闭眼入/需要的扣 1" |
| 无软广句式 | 无"说到这必须提一个东西""这是我最近在用的" |

---

## F. 交付形态（纯文案）

| 检查 | 通过标准 |
|---|---|
| 无时间轴 | 正文没有 `0-8s`、`155-180s`、`前 30 秒` 这类秒数标记 |
| 无段名标签 | 没有"立论/破局/揭秘/支撑/方法/升华"作为小标题或【】标签 |
| 无拍摄建议 | 没有镜头、景别、机位、表演、语速、BGM、剪辑、字幕样式 |
| 可直接念 | 从第一句到最后一句连起来是完整稿件，不需要读者自己拼段落 |

---

## G. 重构合规（与对标内容比对，必跑）

| 检查 | 通过标准 |
|---|---|
| 连续同字 | 与原文无连续 10 字以上相同（公共概念名除外） |
| 开头 | 与原内容首句不同构、不同词 |
| 案例 | 人物关系 / 行业 / 台词，三项至少换两项 |
| 话术 | "可以这样回"的句子为原创 |
| 结构 | 段落顺序至少调整一处，或形式已更换 |
| 换词检测 | 不是仅做同义词替换 |

---

## H. 平台合规

| 检查 | 通过标准 |
|---|---|
| 绝对化用语 | 无"最/第一/顶级/绝对/100%/永久/根治" |
| 功效承诺 | 无治疗、疗效、减肥数字、防病表述 |
| 身份真实性 | 无虚构职位、收入、学历、经历 |
| 焦虑尺度 | 有痛感但不到"恐吓"；"不这样你就完了"必须改软 |
| 类目资质 | 医疗/保健/金融/教育类目，提示用户自行核验资质与广告审查要求 |

## 常见失败模式速查

| 症状 | 病根 | 一句话修法 |
|---|---|---|
| 读起来土 | 语体是口播自述，不是论述 | 前三分之一删掉"你"，把经历换成现象句 |
| 像在念稿给我听 | 全是短句 + 喊话词 | 加两句 30 字以上的推演句，删掉所有"记住" |
| 开头还行，40 秒掉光 | 破局在讲道理 | 把归因反转改成一句机制判断 |
| 完播高，涨粉低 | 全程情绪，没给机制 | 补符咒名 + 三条方法 |
| 收藏高，转发低 | 只解决"我"，没指向"他" | 补一句能指名道姓的类型句 |
| 数据平 | 母题太散 | 连续 5 期同一母题、同一形式 |
| 被判搬运 | 只换了词 | 走 L2/L3 重构 |
