# 08 重构协议：同核换壳

> 这是本专家最重要的一份文件。
>
> 用户可以高频、大量地参考对标账号的现有内容。**参考的是"知识点"和"道理"，不是"文字"。**
> 交付物中不允许出现与对标账号完全一致或高度相似的表达。

---

## 一、一句话原则

**知识同源，文字全新；道理相同，案例不同。**

对标账号证明了一件事：这个道理有人爱听。
你要做的是：**用你自己的一套语言、一套案例，把这个道理再说一遍。** 而不是把那句话搬过来。

---

## 二、三层重构深度（按需选择）

| 层级 | 名称 | 改什么 | 保留什么 | 适用 |
|---|---|---|---|---|
| L1 | 同题异述 | 换句式、换用词、换节奏 | 同一道理，同一概念 | 快速日更，风险最高，必须逐句重写 |
| L2 | 同核异例 | 换案例、换场景、换人群，可换概念 | 同一心理机制 | **默认使用这一层** |
| L3 | 同源异体 | 换形式（清单→拆解→对答→对比） | 同一母题 | 爆款续作、矩阵分发 |

**推荐配比**：L2 占 70%，L3 占 20%，L1 占 10%。

> L1 不是"换近义词"。把"你不是不努力"改成"你并非不勤奋"，仍然是抄袭。
> L1 的正确做法是：保留道理，用完全不同的句法重建——"勤奋从来不缺，缺的是让勤奋生效的结构。"

## 三、四换（每次交付必须至少做到三换）

### 换 1：换案例（最重要）

同一个道理，换一个完全不同的生活场景。

| 原案例方向 | 可替换方向 |
|---|---|
| 职场被塞活 | 亲戚借钱 / 邻居蹭车 / 室友用你东西 / 家长群里被指派 |
| 情侣冷暴力 | 闺蜜已读不回 / 合伙人装死 / 父母冷战 |
| 面试被否定 | 被客户当众挑刺 / 被长辈点评人生 / 被同学会拿来比较 |

**硬规则**：案例的人物关系、行业、物品、对话内容，四项中至少三项不同。

### 换 2：换概念（或换解释角度）

- 若原内容用了「海格力斯效应」，你可以：
  - 用**同一个机制的不同命名视角**讲（"仇恨袋"的比喻），
  - 或换成另一条能解释同一现象的真实概念（"反刍思维""情绪反刍""沉没成本"）。
- 公共概念名（如"沉没成本""达克效应"）本身可以使用——那是公共知识；但**机制解释必须自己写，例子必须自己给**。

**硬规则**：不得沿用原内容的"概念名 + 原解释句"组合。概念名可同，解释必须不同。

### 换 3：换句式

| 原句式 | 换法 |
|---|---|
| 对偶句（"普通人靠拼命，狠人靠系统"） | 改成单句断言 + 一句补充（"系统比勤奋贵。贵在你得先想清楚。"） |
| 排比三连 | 改成两段递进 + 一句反问（反问句只用于中段，不用结尾） |
| "请默念 XX" | 改成把这个名字放进句中（"这四个字叫默认授权"） |
| 引号引用台词 | 改成动作描写（"他把文件推过来的时候，手指还在敲桌子"） |

**硬规则**：句子结构不得与原句同构。原句是"A 不是 B，是 C"，你就不能也写成"A 不是 B，是 C"，哪怕换了词。

### 换 4：换节奏与顺序

六步的**功能**不能少，但**顺序可以调**：

- 标准：立论 → 破局 → 揭秘 → 支撑 → 方法 → 升华
- 变体 A：立论 → 揭秘 → 破局 → 支撑 → 方法 → 升华（先给名字，再拆旧认知）
- 变体 B：立论 → 支撑 → 破局 → 揭秘 → 方法 → 升华（先给现象，再给机制）
- 变体 C：立论 → 破局 → 支撑 → 揭秘 → 方法 → 升华（把机制压到后半段，悬念更强）

换顺序，是最不容易被判定为搬运、又能保持效果的改法。

## 四、五不许（红线）

1. **不许连续 10 个汉字与原内容相同。**（专有名词、公共概念名除外）
2. **不许复用原内容的开头第一句。** 开头是判定抄袭的第一证据。
3. **不许复用原案例**（同一人物关系 + 同一冲突 + 同一句台词，三项同时相同即为复用）。
4. **不许复用原话术句子。** "他这样说，你这样回"的"你这样回"必须是全新的句子。
5. **不许"换词不换骨"。** 只做同义词替换、语序微调、加个"其实"——一律视为抄袭。

## 五、自检方法（交付前必跑）

### 方法 1：并排朗读法
把原内容和你的新稿并排，逐段朗读。任何一段读起来"像同一条"，重写该段。

### 方法 2：十连字扫描
逐句检查是否出现与原内容连续 10 字以上相同的片段。有，立即改写。

### 方法 3：案例替换检验
问自己三个问题：
1. 我的案例，和原案例是同一个行业吗？
2. 是同一种人物关系吗？
3. 有同一句台词吗？
三个都"是"，就是没换。

### 方法 4：作者指纹检验
把这句放进那 5 个对标账号的语录集里，会不会显得"是别人写的"？会，就重写。

## 六、重构示例

### 示例 A（L2：同核异例）

**原内容方向**（道理：越追着报复越被绑住 / 概念：海格力斯效应 / 场景：被同事抢功后反复想）

**重构后**（纯段落交付，不带时间与段名）：

> 有一件事几乎所有人都会做，而且做得毫无察觉：把一段没有结果的对话，在心里重演。
>
> 对方没接电话。于是开始推演：他是不是故意的，是不是已经不耐烦，是不是准备把这件事翻过去。一个人在客厅里走来走去，手机在手上来回翻转，屏幕亮了又暗。
>
> 表面在等一个解释，实际在给自己上刑。对方那边可能已经睡了，这边还在开庭。
>
> 心理学里有个词，叫"反刍思维"。受过委屈的人会反复咀嚼那件事，试图从中找出一个"为什么"。但咀嚼不产生答案，只产生胃酸。
>
> 三件事可以立刻做：把想说的话写下来，不发送；给这件事设一个截止时间；第二天做一件与这个人完全无关的事。
>
> ……

**差异点**：场景从"职场抢功"换成"打电话没人接"；概念从"海格力斯效应"换成"反刍思维"；开头从"清单"换成"类型句"；话术全部新写；人称从第二人称自述改为第三人称指认。

### 示例 B（L1：同题异述）

**原表达**：`不被尊重时，请默念"某某效应"。`
**不合格改写**：`当你不被尊重的时候，请默念"某某效应"。`（换词不换骨，仍是抄袭）
**合格改写**：`有人当着你的面贬你的时候，别急着回击。先在心里过一道手续：这件事，值不值得我动情绪。`
**再合格改写**：`他贬你那一秒，你只需要做一件事——把嘴闭上，把眼睛抬起来，看他三秒。`

### 示例 C（L3：同源异体）

原内容是一篇"清单体"（8 条人性铁律）。
重构为一个"拆解体"：先立一个流行说法（比如"吃亏是福"），再逐层拆掉它为什么在这个时代失效，用同一批知识点做证据，最后落到 3 条可用的判断。

**不许改成"自白体"**——讲"我认识的一个老板如何被坑"，会立刻变成口播自述，违反 `09-voice-texture.md`。

同一母题，同一批知识点，形式完全换掉——这是矩阵分发最安全、也最有效的方式。

## 七、允许与禁止的边界（明确版）

| 行为 | 判定 |
|---|---|
| 使用同一个心理学概念名（沉没成本） | ✅ 允许，公共知识 |
| 自己重写该概念的机制解释 | ✅ 必须 |
| 使用同一个心理学概念名 + 同样的一句解释 | ❌ 禁止 |
| 用同一个标题公式（"X 时，请 Y"） | ✅ 允许，公式不是作品 |
| 标题与原标题 80% 字词相同 | ❌ 禁止 |
| 引用原内容的一句话作为"有人说" | ⚠️ 慎用，最多一次，且必须明确引用来源并加以反驳 |
| 复述原内容的观点 | ✅ 允许，观点不受版权保护 |
| 照搬原内容的案例、句子、结构顺序 | ❌ 禁止 |
