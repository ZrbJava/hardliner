# 01 账号系统：昵称、简介、头像、背景图、人设

> 本文件是"狠人思维"账号的外壳规范。所有结论来自对 5 个同类代表账号的公开主页观察（昵称、简介原文、头像视觉、置顶与高赞内容），加上同赛道样本的横向比对。
>
> **样本说明**：这 5 个账号的主页笔记流需登录才能完整展开，后台数据（完播、涨粉、转化）不可见。因此本文件区分两类结论：
> - **硬结论**：多个账号同时出现的表层特征（命名结构、简介句式、头像视觉语法）——这些是可直接复用的。
> - **软推断**：由表层特征反推的内容策略——使用时要结合自己账号数据验证。

**共性（硬结论）**

1. 五个里有四个直接使用"狠人/内核/觉醒"这类**身份词根**，没有一个是"XX 老师""XX 说""XX 日常"。
2. 简介**全部是判决句**，没有一句自我介绍，没有一句"分享/记录/陪你成长"。
3. 简介**全部否定某个主流信念**（温顺、拼命、努力、鸡汤），否定对象就是他们的人设对手。
4. 简介**全部使用句号断句**，2–3 句，最长的一句 30 字以内。零 emoji。
5. 头像**全部为去人格化的人物形象**（遮脸的人，不是生活照，也不是物品或图腾）。

**软推断（内容策略）**

- 昵称里的"思维/进化"不是装饰，是**给观众一个"这里能拿到东西"的预期**，这直接提高了收藏率和关注率。
- "不负责治愈"这类免责宣言，本质是**提前筛人**：留下愿意被刺痛的人，这类人更愿意跟着一个态度明确的人走。
- 越不写"我是谁"，越方便换人出镜、批量起号、矩阵化运营。这是这类账号能工业化生产的前提。

> **命名口径（v2.7）**：昵称只用"强者系"词池组合（A 身份 / B 机制 / C 结果），词池见第二节。表里的"内核/觉醒/模型库/计划"只作观察记录，**不再直接照抄成名字**。

## 二、昵称（强者系词组合，直接给名字）

### 词池（三层，只在层内取词组合）

**A 身份（必须有一个）**：`狠人` · `强者` · `高手` · `猛人`

**B 机制 / 内容**：`思维` · `认知` · `进化` · `觉醒` · `开窍` · `破局` · `升维` · `逻辑` · `法则` · `规律` · `心法` · `算法` · `模型` · `系统` · `博弈` · `底层`

**C 结果 / 场域（可选）**：`格局` · `阶层` · `人性` · `权力` · `手腕` · `气场` · `翻身` · `逆袭` · `硬核` · `清醒` · `执行力` · `止损`

**连接字**（最多一个）：`的` `者` `论` `派` `集`

### 组合规则

- 一条昵称 = **A + B**，或 **A + B + B**，或 **A + B + C**，最多三到四段。
- A 组必须出现，不许只有"思维/认知"这类没有主语的词。
- 长度 **4–8 字**，超过 8 字在评论区和小红书卡片里会被截断。
- 全中文，不加数字、不加英文、不加符号。

### 风格锚（这一批就是标准，照着这个硬度往外延）

狠人思维 · 强者进化 · 高手思维 · 狠人底层逻辑 · 强者认知 · 高手破局 · 狠人进化论 · 强者思维论 · 高手认知升维 · 狠人心法 · 强者底层规律 · 高手进化论 · 狠人升维 · 强者格局 · 高手执行力 · 狠人博弈论

### 硬约束

- **只许用词池里的词**，不引入任何其他名词。棋子、棋局、钝刀、光、影、星、海、尘埃、少年、树洞、猫、糖、酒、花——全部不许，这些词看着"高级"，实际把账号的气放掉了。
- 不用"小 X""阿 X""XX 的日常""XX 日记""记录""手记"。
- 不用"老师""导师""教练"——这套叙事里，说教者是被嘲笑的对象。
- 不加 emoji、不加数字后缀（666、888）、不加标点。

### 输出方式

**直接给名字，一行一个，12–16 个。** 不给命名公式、不给结构拆解、不给"这个适合什么方向"的解释。用户要的是能直接挑的选项，不是命名课。

- ✗ 错误：`公式：身份词根 + 内容容器。示例：狠人操作系统——适合卖方法论、0 粉起号。`
- ✓ 正确：`狠人思维 / 强者进化 / 高手破局 / 强者认知 / 狠人进化论……`

同一批里不要出现只差一个字的两条（如"狠人思维"和"狠人思维论"只留一条）；也不要两条都是同一个 A 组词开头，A 组四个词要轮着用。

## 三、简介公式（三段式）

```
① 否定前提（撕掉他信的东西）
② 病理化论断（给他的现状命名，且命名要狠）
③ 免责 + 宣言（我不做什么，我只做什么）
```

### 结构拆解

| 段 | 作用 | 句式模板 |
|---|---|---|
| ① | 制造认知冲突，3 秒定调 | `[主流信念] 救不了你。` / `这个世界从不奖赏 [X]。` |
| ② | 把痛苦变成一个"病名" | `[你现在的状态]，是 [狠词]。` 狠词库：自我剥削、权限外泄、免费劳动力、退让惯性、默认授权 |
| ③ | 筛人 + 立威 | `不负责 [A]，只负责 [B]。` / `这里没有 [A]，只有 [B]。` |

### 三版示范（原创，可直接改用）

**否定型**
> 懂事换不来尊重，只会换来得寸进尺。
> 善良若是免费，就不叫善良。
> 这里不讲道理，只讲结构。

**宣言型**
> 运气决定不了位置，结构才会。
> 不教人变坏，只教人不再免费。
> 每条都给出一个能用的东西。

**免责型**
> 不哄人，不劝和，不陪聊。
> 只做一件事：把那些被说成"算了"的瞬间，一个一个找出来。
> 不接受这套的，不用关注。

### 禁忌清单

- 不写"热爱生活""分享日常""感谢关注""合作私信"（合作方式放主页其他位置或置顶评论）。
- 不用问句结尾（问句削弱权威）。
- 不超过 3 句、60 字。
- 不出现 emoji 和感叹号。

## 四、人设四要素

这套账号的人设不是"我是谁"，而是"我凭什么这么说"。四要素缺一不可：

| 要素 | 内容 | 作用 |
|---|---|---|
| **身份** | 过来人（我挨过）／揭穿者（我看穿了）／同类幸存者（我跟你一样，但我爬出来了） | 决定语气：过来人=平静，揭穿者=冷，幸存者=近 |
| **伤疤** | 一个具体的、可复述的失败（被合伙人坑、被亲戚借走 20 万、被领导当众否掉方案） | 建立可信度，避免"成功学讲师"感 |
| **武器** | 一套命名过的系统（三句话、四个模型、一条底线） | 观众关注的理由，也是内容能连续做的骨架 |
| **边界** | 不治愈、不劝和、不陪聊、不带软货 | 制造"稀缺感"与"过滤感" |

**人设自检三问**

1. 这个人设，说话会不会笑？——会笑就还不够狠，改成"最多冷笑"。
2. 这个人设，会不会主动私信安慰粉丝？——会，就砍掉，改成"评论区见"。
3. 这个人设，能不能连续讲 30 期不重复？——不能，说明"武器"不够结构化。

## 五、头像视觉语法（人像 + 暗场 + 强符号）

观察样本中"狠人模型库"的头像：**黑金盔甲骑士，赤红披风，红色发光眼缝，头戴王冠，暗红渐变背景，半身 3/4 侧脸，无露脸**。这不是偶然审美，是这套账号的最优解。

### 第 0 条硬规则：头像必须是一个人

**头像的主体只能是一个人的半身像或胸像**，头、颈、肩至少能看到两处。这是硬性要求，优先于任何风格偏好。

**一律不许**：兽首/鹰/狼/狮、棋子、刀剑单独陈列、空盔甲、面具浮空、静物、建筑、logo、纯图形符号、文字排版、风景。

符号（王冠、刀、锁链、棋子）**只能穿在人身上或被这个人握着**，不能自己当主角。如果生成结果里看不到人，就是废图，重出。

### 五个必备要素

1. **暗场底色**：墨黑 `#0B0B0C`、炭灰 `#1C1C1E`、暗血红 `#3A0D10`、墨绿 `#16241F`。禁止纯白、浅色、渐变糖果色。
   **注意**：暗场指的是**背景**，不是主体。主体必须被光打亮、材质可辨，不许整体压黑（详见 `05-visual-system.md` 第零节曝光底线）。
2. **去人格化（但仍是人）**：全盔、兜帽、面具、背影、侧影、半脸柔阴影。**不露正脸**，但必须是个具体的人——有肩线、有身体、有衣料。
   **去人格化 ≠ 剪影，也 ≠ 去掉人**：不露脸靠遮挡实现，不靠压黑或砍掉身体实现。
3. **单一强符号**：王冠、长刀、锁链、棋子、门、钥匙。一个就够，两个就乱，且必须由这个人佩戴或手持。
4. **金属/皮革材质**：黑金、哑光钢、磨砂皮革。质感要"沉"，因为沉=压得住场。
5. **一点血色**：红色发光点、红披风、红瞳、红线。占比 5–10%，是全图唯一的"活气"。

### 为什么必须这样

- **形象统一**：统一形象、不露正脸，账号就不绑死在某个人身上，换主播不出戏，也能矩阵化。
- **降低网红感**：真人美颜头像会触发"又是一个卖课的"防御，遮脸的强形象反而像"某种存在"。
- **可复用**：任何一期文案配这张头像都不违和，因为头像不表达具体情绪，只表达"硬度"。
- **必须亮到看得见**：暗调只是背景色，不是曝光值。头像在信息流里只有 48px，看不见材质的图等于没有头像。

### 六种可直接用的头像方向（全部是人）

| 方向 | 描述 | 适配内容 |
|---|---|---|
| 黑金骑士（默认） | 一个穿全盔重甲的人，王冠嵌在头盔上，红披风，盔甲纹理清晰 | 综合，最通用 |
| 冷光侧脸 | 三十多岁男性 3/4 侧脸，颧骨/下颌/鼻梁被主光照亮，眼睛在柔阴影里 | 形象、气场、职场 |
| 兜帽正视 | 一个戴深色兜帽的人，帽檐压住上半脸，只露下颌与嘴 | 人性、识人、关系 |
| 背影持刀 | 一个人的背影或侧背，肩线被轮廓光勾亮，手握刀，刀身有金属高光 | 强势人设、边界 |
| 单眼特写 | 一张脸的下半部 + 一只睁开的眼，眼周皮肤纹理被侧光照亮 | 认知、觉醒、心理 |
| 西装暗场人像 | 一个人穿黑衬衫或黑西装，领口解开，下颌线与喉结被光切出 | 职场、钱、阶层 |

> 六种都要求：单人、半身/胸像、主体占宽 45–65%、背景比人暗、脸上或身上有一处高光。

## 六、背景图语法

> **铁律：每张背景图都要有一句金句。** 空白底图在主页上只是一块平色，既没信息也没态度。金句由本地脚本叠上去，不交给模型写中文。

### 两种版式

**A. 暗场 + 一行金句**（最稳，默认）
- 底色：墨黑或径向暗红，但必须有氛围与材质（烟雾、浮尘、石面纹理、光带），不许是纯渐变
- 文字：居中偏上 1/3，一行，≤12 字，骨白 `#E8E2D6` 或暗金 `#C9A227`
- 字号：图高的 6–8%
- 留白：下半部 40% 必须留空（会被头像、昵称、数据压住）

**B. 暗场 + 符号放大 + 短句压角**
- 把头像里的符号（刀、盔甲纹样、锁链）放大铺在右侧，只留局部
- 配一句 ≤8 字的短句压在左下角或右下角，字号小一号
- 适合已经有辨识度之后用，做视觉记忆点

优先用 `03-hook-quote-bank.md` 的金句库，其次用下面这批标语。**不许与本期视频标题、简介原句重复**——三个位置同一句话，等于浪费三次曝光。

## 七、四件套一致性校验（交付前必跑）

| 检查项 | 通过标准 |
|---|---|
| 昵称 ↔ 简介 | 昵称里的"思维/进化"必须在简介或内容里兑现，不能挂羊头 |
| 简介 ↔ 头像 | 简介说"不负责治愈"，头像就不能是暖色调笑脸 |
| 头像 ↔ 背景图 | 同一色系（黑/暗红/暗金），背景图不得出现第二种材质语言 |
| 头像 ↔ 内容 | 头像的"硬度"必须高于文案的"狠度"，宁硬勿软 |
| 四件套 ↔ 内容调性 | 讲"被欺负"的号不要用暖光笑脸；讲阶层与钱的号必须用金属/暗金质感，不用柔光插画 |
