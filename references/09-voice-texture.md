# 09 语体与质感：写判断，不写自述

> 这一份决定"读起来像什么"。结构对了但语体错了，稿子会显得土、显得像在对镜头讲自己的事。
> **一句话总纲：像一个人在纸上判断世界，不像一个人在镜头前讲自己的故事。**

---

## 零、两条底层差别

| | 口播自述体（禁止） | 书面论说体（唯一标准） |
|---|---|---|
| 说话人位置 | 当事人，讲我遇到的 | 观察者，讲世界怎么运转 |
| 素材来源 | 我的经历 | 可被任何人验证的现象 |
| 句子功能 | 让你共情我 | 让你承认一个判断 |
| 时间 | 那年、上周三、大年初二 | 一直、每一次、当……时 |
| 落点 | 我当时多难受 | 这件事的机制是什么 |
| 读完感觉 | 听了一个故事 | 被指出一个事实 |

**为什么必须换**：自述体靠"我"的可信度成立，而这个账号的"我"是虚构的，一旦被听出是编的，整套内容作废。论说体不依赖讲述者的身份，只依赖判断是否成立——所以它可以无限量生产，也不会因为换人出镜而崩。

---

## 一、八种"土"，逐条禁

### 1. 判决公式外露
`你不是X，你是Y` 连用两次以上，结构就露出来了，读者会开始数你的模板。
- ✗ 你不是心软，你是怕别人说你变了。你不是没边界，你是边界上贴着欢迎光临。
- ✓ 一个人被反复占用，通常不是因为心软。是因为他从没让人为占用付过一次代价。

**允许用一次，不许连着用。** 这是硬上限。

### 2. 身体反应清单
喉咙发紧、手心出汗、耳朵发烫、心里咯噔一下、手指停在半空——这些是共鸣的最低成本手段，用一次叫准确，用两次叫套路。
- ✗ 你笑着，筷子停在半空，手心是凉的。
- ✓ 你说了行。然后低头，继续改那份不属于你的文件。

**判据：旁人看得见的是动作，看不见的是喉咙。写看得见的。**

### 3. 家常场景直译
"大年初二，饭桌上还剩半盘饺子""上周三晚上九点，办公室只剩你们两个人"——没有精确观察支撑的家常细节，一律变成段子。
- ✗ 大年初二，饭桌上还剩半盘饺子，他先给你倒了一杯酒。
- ✓ 亲戚开口借钱，通常不直接从钱开始。他先聊行情，聊孩子，聊到你觉得欠他一场倾听。

例外：你确实有一个旁人想不到的观察（比如"他先把酒杯推到你手边，才提数字"）。**只有观察本身有新信息时才写具体场景。**

### 4. 喊话口头语
听好了 / 记住 / 说白了 / 我给你讲 / 这条别划 / 三句话背下来 / 说句难听的 / 我告诉你。

这些词的功能是模拟现场感，副作用是把文字降成地摊腔。**全文 0 个。**

### 5. 江湖词汇
搞钱、向上社交、破防、扎心、狠一点、搞事业、认知觉醒、降维打击、拿捏、松弛感、钝感力、磁场、能量、闭环、颗粒度、底层逻辑（已用滥）。

### 6. 反问轰炸
连续两个以上"你以为……？其实……"。反问是加压，连着用会变成审讯，读者会防御。
**每篇反问 ≤ 2 个，且不许相邻。**

### 7. 排比到失真
三短一顿、五短一停，全篇像鼓点。这是喊麦的节奏，不是判断的节奏。
**排比最多三句一组，全篇不超过两组。**

### 8. 劝服式收尾
从今天起，把"行"从你的字典里删掉 / 愿你…… / 你要开始爱自己。
命令式收尾看似有力，实际是把判断降级成口号。

## 二、五种"自述感"，逐条禁

### 1. 第一人称往事
我以前也这样 / 那年我 / 我表弟 / 我带了三个学员 / 我做了十年 HR。

**"我"全文最多 2 次，且只能是判断，不能是经历。**
- ✓ 我不认为这是善良。（判断）
- ✗ 我以前也这么借出去两万。（经历）

### 2. 时间锚点开场
用具体某一天开场，等于宣布"我要讲故事了"。故事的信任成本高，判断的信任成本低。

### 3. 对话剧本
他说……你回……他又说……你回……三轮以上。这是小品结构。
**话术只给"可以直接说出口的那一句"，不演示对手的台词。**

### 4. 情绪自陈
我当时特别委屈 / 说实话我有点难受 / 说不心疼是假的。

### 5. 自证式权威
我见过太多人 / 我带过几百个学员 / 这个行业我太熟了。凡是靠"我经历过"建立可信度的句子，全部删。

---

## 三、替换原则：把经历换成现象

自述体写"我遇到了什么"，论说体写"这类事为什么总发生"。三种句式轮换使用：

| 句式 | 模板 | 例 |
|---|---|---|
| 现象句 | 总有人…… / 你会发现…… | 总有人在被占用之后，还替对方找理由。 |
| 类型句 | 有一类人…… / 这类人有一个共同点 | 有一类人从不拒绝，也从不迟到，最后被默认为"可以再加一点"。 |
| 观察句 | 这种场面你见过，但很少有人注意到…… | 这种场面你见过：一个人被当众打断，然后他笑了笑，把话咽回去了。 |

**这三种句式是整套内容的主力。** 写不出场景时不要编故事，改用类型句。

---

## 四、书面论说体的六条句法

1. **判断先行，解释后置。** 先说结论，再给理由。反过来就成了讲课。
2. **允许长句。** 平均 18–26 字，单句上限 45 字。一句长、一句短，交替出现。
   （旧标准是 12–18 字全短句，那是喊话节奏，已废止。）
3. **用名词性短语承担概念**：退让的惯性、沉默的许可、被默认的位置。不用形容词堆叠（"特别特别委屈"）。
4. **转折只用三个词**：但、只是、问题在于。禁用"然而、不过、其实呢、话说回来"。
5. **举例不用"我朋友"**：用"一个人""一个部门""某家公司""这类合作"。
6. **段尾落在判断，不落在抒情。**
   - ✗ 那一刻，你终于明白，你一直是一个人。
   - ✓ 位置不是别人给的，是你让出来的。

## 五、人称配比（照这个比例写）

| 人称 | 上限 | 用在哪 |
|---|---|---|
| 你 | 10 次 | 只在需要精准打击的那一两句；其余交给"人" |
| 人 / 一个人 / 大多数人 / 这类人 | 不限 | 承担普遍性，这是主力 |
| 我 | 2 次 | 只用于判断（我不认为……）或命名（我把它叫做……），不用于经历 |
| 我们 | 2 次 | 只在共同处境（我们都学过一套错的东西） |

**位置规则（比次数更重要）**：**前三分之一不许出现"你"。**

先用"一个人""他""这类人"把现象讲清楚，让判断自己站住；到方法段和结尾再转向"你"，这时"你"才有打击力。
- ✗ 开头就是"你有没有过这种时候"——这是口播，把观众按在椅子上说话。
- ✓ 开头讲一群人的共同处境，结尾才落到"你"——这是论述，读者自己认领。

**通篇"你"是最典型的口播特征**——镜头对着一个人说话。改成"人"，文字立刻从对话变成论述。

## 六、场景写法：外部可观察

公式：`场合 + 一句话 + 一个旁人看得见的动作`

| | 写法 |
|---|---|
| ✗ 内部感觉 | 你喉咙发紧，手心出汗，耳朵发烫 |
| ✓ 外部动作 | 你说了"行"，然后把那份文件拖进了自己的文件夹 |
| ✗ 心理描写 | 你心里其实特别不愿意 |
| ✓ 行为证据 | 你打开文档，改了两行，又关掉 |

**原则：一个人的处境，看他做了什么，不看他说自己多难受。**

---

## 七、概念名要像符咒，不像教材

- **4–6 字**，能被单独引用、能被默念。
- 结构：动词性名词 + 对象。例：默认授权 / 退让惯性 / 位置让渡 / 沉默定价（✗ 价格类，禁用）/ 预期管理 / 权限试探。
- **不首选"某某效应"。** 教学腔的名字现在很廉价，且撞款率高。真实概念可以用，但要用它做"证据"，不要用它做"招牌"。
- 每个名字必须配一句**机制句**（≤25 字），说清"为什么会这样"。
- 自造名必须写成"我把它叫做……"，不许伪装成学术定论。

**符咒三问**
1. 这四个字，观众能不能不打磕巴地说出来？
2. 能不能不加解释就懂个七八成？
3. 说出来会不会显得像在念论文？

## 九、十组对照改写（照这个力度改）

| ✗ 土 / 自述 | ✓ 判断 / 论说 |
|---|---|
| 你不是不努力，你是没有议价能力。 | 努力之所以换不来位置，是因为它从不稀缺。 |
| 上次我表弟找我借钱，我一句话就挡住了。 | 亲戚开口借钱时，第一句通常不提钱。他要先确认你有没有拒绝的习惯。 |
| 记住：善良要带牙齿。 | 善良是一种需要成本的东西。免费的那部分，别人不叫善良，叫好用。 |
| 那一刻我喉咙发紧，说不出话。 | 他把话说完了，你点了头。会议记录里，这件事就这么定了。 |
| 听好了，这三句话背下来。 | 有三句话可以用，按难易排序。 |
| 三句话，让他再也不敢催你。 | 让人停止催促的，不是速度，是你给过一次明确的边界。 |
| 说白了，人都是欺软怕硬的。 | 人对边界的判断，来自试探的成本，不来自对方的品格。 |
| 我以前也这样，被坑了很多次才明白。 | 这类误判很常见：把一次让步当成一次善意。 |
| 从今天起，把"行"从你的字典里删掉。 | 下次说"行"之前，先给它加一个条件。 |
| 你以为他在帮你，其实他在收买你。 | 帮忙和收买在外观上一样，区别在于事后有没有账单。 |

## 十、语体自检五问（交付前逐条过）

1. **把第一句单独拿出来**：它是一句判断，还是一段故事的开头？是故事，重写。
2. **数一下"我"**：超过 2 次，删。
3. **数一下身体反应词**：出现 2 个以上，改成外部动作。
4. **看最长那句**：是否超过 45 字？全篇是否全是 15 字以内的短句？两头都算错。
5. **把整段念一遍**：像不像有人在念稿子给你听？像，说明太口播；像不像有人在写给你看？不像，重写。

**最终判据一句话**：读完应该觉得"他说得对"，而不是"他讲得真惨"。
